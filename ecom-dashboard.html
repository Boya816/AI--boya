📐 指标口径 & 排查逻辑说明 ▼
NMV：净成交额 = UV × CVR × ASP（扣除取消/退货后口径）
UV：独立访客数（去重）
CVR：转化率 = 订单数 ÷ UV
ASP：客单价 = NMV ÷ 订单数
TSI：总销售件数（按 SKU 出货）
WoW：周环比 = (本周 - 上周) ÷ 上周
YoY：同比 = (本期 - 去年同期) ÷ 去年同期
YTD：年初至今累计 NMV
vs Goal：达成率 = 实际 NMV ÷ 目标 NMV
渗透率：海外仓 NMV ÷ 站点总 NMV
TSI：总件数；Live Listing：当前在架 SKU 数
排查逻辑：
① 先看大盘 WoW/YoY：整体异动还是个别品类？
② 若是个别品类/单品 → 拆解 NMV = UV × CVR × ASP，找跌幅最大分量
   • UV 大跌 → 流量问题（大促回落/竞品抢量/资源减少）
   • CVR 大跌但 UV 正常 → 转化问题（价格/详情页/评价/竞品降价）
   • ASP 异常高/低 → 价格带偏移（促销集中/爆款结构变化）
③ 若是大盘整体 → 先判断是否大促回落（看周期环比），再看竞品
